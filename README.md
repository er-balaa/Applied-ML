# Applied ML

A structured repository documenting my hands-on learning journey in Machine Learning using Scikit-learn, covering both supervised and unsupervised learning techniques with practical implementation, preprocessing workflows, and model evaluation.

## Overview

This repository contains implementations, experiments, and notes for core Machine Learning algorithms and concepts using Python and Scikit-learn. The focus is on understanding both theoretical concepts and practical applications with real-world datasets.

## Topics Covered

### Supervised Learning
- Linear Regression
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest

### Unsupervised Learning
- K-Means Clustering
- Principal Component Analysis (PCA)

### Data Preprocessing
- Feature Scaling
- Data Cleaning
- Handling Missing Values
- Train-Test Split
- Feature Engineering

## Technologies Used
